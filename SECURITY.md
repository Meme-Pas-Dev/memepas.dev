# Security / Sécurité

## English

To report a security issue with the memepas.dev website, please use GitHub's private
vulnerability reporting: **Security** tab → **Report a vulnerability**. Please do not open a
public issue.

For an issue in one of the applications, use the security policy of that application's
repository.

## Français

Pour signaler un problème de sécurité sur le site memepas.dev, utilisez le signalement
privé de GitHub : onglet **Security** → **Report a vulnerability**. Merci de ne pas ouvrir
de ticket public.

Pour un problème dans l'une des applications, suivez la politique de sécurité du dépôt de
cette application.
