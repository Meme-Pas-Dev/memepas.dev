# Changelog / Journal des modifications

## [1.1.4] - 2026-10-20

### English

- Quayline page: the local terminal (Quayline 1.11) is now described, with its keyboard
  shortcut and its absence from the Flatpak; the Windows installation notes that it is
  off by default.

### Français

- Page Quayline : le terminal local (Quayline 1.11) est désormais présenté, avec son
  raccourci et son absence du Flatpak ; l'installation sous Windows précise qu'il est
  désactivé par défaut.

## [1.1.3] - 2026-10-19

### English

- The site is rebuilt every three hours instead of once a night, so new application
  releases appear sooner.

### Français

- Le site est reconstruit toutes les trois heures au lieu d'une fois par nuit : les
  nouvelles versions des applications y apparaissent plus vite.

## [1.1.2] - 2026-10-17

### English

- Link preview images updated to the 1.1 design: pictograms, and the deep blue dark theme
  for the Quayline page.

### Français

- Images d'aperçu des liens mises à jour selon la version 1.1 : pictos, et thème sombre
  bleu nuit pour la page Quayline.

## [1.1.1] - 2026-10-17

### English

- The download card shows the right version for the visitor's system from the first
  display, and the downloads filter no longer pushes the page down: no more layout shift
  while loading.
- Text and heading fonts are preloaded, so the page no longer moves when they replace
  the fallback font.
- Scrollable command blocks can be scrolled with the keyboard.

### Français

- La carte de téléchargement affiche dès le premier affichage la variante adaptée au
  système du visiteur, et le filtre des téléchargements ne décale plus la page : plus de
  saut de mise en page au chargement.
- Les polices du texte et des titres sont préchargées : la page ne bouge plus quand elles
  remplacent la police de secours.
- Les blocs de commandes qui défilent sont accessibles au clavier.

## [1.1.0] - 2026-10-17

### English

- Pictograms throughout the site, in four soft tints: principles, catalogue, features,
  security, installation, downloads and legal information.
- New deep blue dark theme, easier to read.

### Français

- Pictos sur l'ensemble du site, en quatre teintes douces : principes, catalogue,
  fonctionnalités, sécurité, installation, téléchargements et informations légales.
- Nouveau thème sombre bleu nuit, plus lisible.

## [1.0.2] - 2026-10-17

### English

- Navigation: on the home page, the active link follows the section being viewed
  (Home, Apps, About); links no longer shift when the active one changes.

### Français

- Navigation : sur l'accueil, le lien actif suit la section affichée (Accueil,
  Applications, À propos) ; les liens ne se décalent plus quand le lien actif change.

## [1.0.1] - 2026-10-17

### English

- Site source code published under the MIT License; names, logos, icons,
  screenshots and preview images are excluded.
- Accessibility barriers are now reported by email.
- Privacy policy: mention of the script monitoring performed by Cloudflare.

### Français

- Code source du site publié sous licence MIT ; noms, logos, icônes, captures d'écran
  et images d'aperçu en sont exclus.
- Les obstacles d'accessibilité se signalent désormais par e-mail.
- Politique de confidentialité : mention de la surveillance des scripts effectuée par
  Cloudflare.

## [1.0.0] - 2026-10-16

### English

- First version of the site, in French and English: home page, Quayline page,
  downloads and legal information.
- Language chosen from the browser's preferences on the home address, without cookies.
- Quayline page: download suited to the visitor's system, screenshots, features,
  security model and step-by-step installation.
- Latest application versions read from GitHub when the site is built.
- Light and dark themes, works without JavaScript, no external resources, strict
  content security policy.
- Structured data and preview images for search engines and link sharing.

### Français

- Première version du site, en français et en anglais : accueil, page Quayline,
  téléchargements et informations légales.
- Langue choisie d'après les préférences du navigateur sur l'adresse d'accueil, sans
  cookie.
- Page Quayline : téléchargement adapté au système du visiteur, captures d'écran,
  fonctionnalités, modèle de sécurité et installation pas à pas.
- Dernières versions des applications lues sur GitHub à la construction du site.
- Thèmes clair et sombre, fonctionnement sans JavaScript, aucune ressource externe,
  politique de sécurité du contenu stricte.
- Données structurées et images d'aperçu pour les moteurs de recherche et le partage de
  liens.
